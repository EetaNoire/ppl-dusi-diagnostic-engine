## Overview
The PPL–DUSI Diagnostic Engine v4.11 is an educational, browser-based clinical decision-support prototype designed to operationalize the **Premature Psychiatric Labelling (PPL)** and **Duration of Untreated Somatic Illness (DUSI)** framework.

It provides an interactive demonstration of the three-component Clinical Safeguard Protocol:
1. **First-Episode Somatic Screen (FESS)**: Tiered laboratory screening graded by evidence levels.
2. **Temporal Medication & Exposure Map**: A 6-month lookback to identify pharmacological triggers and depletion syndromes.
3. **EHR-Enforced Diagnostic Pause**: A structured override mechanism designed to interrupt cognitive bias and premature closure at the point of first-episode psychiatric coding.

## How to Use
1. Download the `index.html` file (or clone this repository).
2. Open the file in any modern web browser (Chrome, Firefox, Safari, Edge).
3. **No installation, server, or internet connection is required.**
4. **Privacy:** All data processing occurs locally in your browser. No patient data is transmitted, stored, or logged.
